# SmartVoice

Multilingual speech sinthesizer and TTS engines aggregator for Android
that can automatically recognize input text language by its nature and
choose an appropriate voice to pronounce it.

     alt="Get it on F-Droid"
     height="80">](https://f-droid.org/packages/tts.smartvoice/)

See
[the application website](https://poretsky.github.io/android/smartvoice)
for more details.
