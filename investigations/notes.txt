Here are some means to build and test language recognition criteria.


Use following commands:

make -- Compile research utility and test.jar library.

make test -- Perform recognition test for all supported languages.

make test language=<language_name> -- perform recognition test for
specified language.

make check language=<language_name> -- Check criterion quality for
specified language.

make audit language=<language_name> -- Audit criterion for specified
language. Uses <language_name>.json as criterion data source and
results/<language_name>.unique.ranks which should be generated
previously.

make ranks -- Generate .ranks files in the results subdirectory. Might
be time consuming.

make <language_name> -- Generate a bunch of files in the results
subdirectory needed to build criterion for specified language. Time
consuming operation.

make everything -- Perform latter operation for all available
languages. Very time consuming.

make clean -- Remove intermediate files and volatile results.

make distclean -- Remove all autogenerated files.


To test markup facility perform following command:

java -jar test.jar -extract multilang_file.txt


To generate Bloom filters rename bf-conf.json.inactive to bf-conf.json
and perform any of test, check or audit commands listed above.
